# AWS Cloud-Based IT Infrastructure & Support Lab

## Project Overview

This project demonstrates a small AWS cloud infrastructure environment combined with practical IT Support and Linux troubleshooting.

## AWS Services Used

- Amazon VPC
- EC2
- EBS
- S3
- IAM
- CloudWatch
- Internet Gateway
- NAT Gateway
- Route Tables
- Security Groups
- Network ACLs
- Availability Zones

## Project Objectives

- Build a basic AWS network using VPC and subnets
- Deploy and access a Linux EC2 server
- Configure AWS security controls
- Store objects using Amazon S3
- Configure IAM permissions
- Monitor EC2 using CloudWatch
- Practice Linux IT Support troubleshooting

## Monitoring

CloudWatch was used to monitor EC2 CPU utilization.

A CPU stress test was performed to increase CPU usage and verify the CloudWatch alarm.

## IT Support Troubleshooting

Linux commands were used to troubleshoot:

- Network connectivity
- File permissions
- Disk usage
- Storage
- Services
- System logs
- Memory usage

## Security

The project includes:

- Security Groups
- Network ACLs
- IAM permissions
- S3 security settings
- Least-privilege access

## Project Architecture

The architecture diagram shows the relationship between the AWS Region, VPC, subnets, gateways, EC2, security controls, S3, IAM and CloudWatch.
